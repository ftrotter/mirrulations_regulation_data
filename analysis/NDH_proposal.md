# NDH Alternative Proposal — Related Comments (Stage 3)

This file catalogs the Stage 3 comment markdown that discusses the
**National Directory of Healthcare Providers & Services (NDH) Implementation
Guide** — the "alternative proposal" in CMS-0062-P, Section II.E.3, to use the
NDH IG **Endpoint Profile** for payer API endpoint reporting.

The motivating concern is that the alternative proposal uses **only** the
Endpoint Profile, whereas the full NDH IG also defines **Insurance Plan**,
**Payer (Organization)**, and other profiles that are arguably needed to make
endpoint reporting meaningful. Comments that agree — that is, that criticize
an endpoint-only approach and argue for doing more with the NDH / FHIR
implementation guide — are called out below.

Each comment is linked to its local Stage 3 markdown file and, where
available, to the original attachment on Regulations.gov.

## Key takeaways

- **AHIP** most directly agrees with the concern: it states that reporting a
  simple list of endpoints will not solve discovery because payers are complex
  organizations with layers of hierarchy that determine which endpoint to use.
- **Jefferson Health Plans** notes CMS's own materials acknowledge the NDH IG
  cannot accommodate multiple URLs per payer entity or the required per-URL
  metadata — i.e., the Endpoint Profile alone is insufficient.
- **HL7 International**, **Smart Health Network**, and **b.well** urge CMS to
  adopt the full FAST NDH IG (plus FAST Security) rather than only endpoint
  URLs, and to capture trust, OAuth, certificate, and security metadata.
- **Consumers' Checkbook** is the comment that explicitly works with the
  **Insurance Plan** profile, proposing a FHIR Network Identification Number
  that lives in `InsurancePlan` and propagates across `Coverage`,
  `ExplanationOfBenefit`, and `PractitionerRole` / `OrganizationAffiliation`.
- A smaller group (**Flexpa**, **AMA**) criticizes the NDH Endpoint Profile in
  the opposite direction, preferring a simpler flat list or the primary FHIR
  Endpoint Resource format.

- Searched Stage 3 markdown (`data/markdown_db/stage003_structure_discovery/`),
  comments only, using `grep` for `" NDH "`, `"Alternative Proposal"` (and related
  phrasings: `NDH`, `National Directory of Healthcare`, `Endpoint Profile`,
  `Insurance Plan`, `Plan-Net`).
- The proposed-rule document (`CMS-2026-1255-0001_content.html.md`) is excluded;
  it is the agency text that defines the alternative proposal, not a comment.
- A few comments matched `"alternative proposal"` only for a *different*
  alternative proposal in the rule (the PDex US Drug Formulary IG, the
  CRD/DTR/PAS expiry, or referral-certification FHIR), and were excluded as not
  being about NDH.
